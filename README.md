# Simply Some Cards

A responsive job listing UI built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**.

This project demonstrates dynamic data rendering, reusable component architecture, and local UI state management using React.

---

## 🚀 Features

- Responsive grid layout
- Reusable Card component with typed props
- Dynamic job data rendering
- Bookmark toggle interaction (local state)
- Clean layout with premium spacing system
- Fully built using Tailwind utility-first styling

---

## 🧠 What This Project Demonstrates

- Component-based architecture
- Props and data flow in React
- TypeScript interface usage for component contracts
- Local state management with `useState`
- Controlled layout using responsive design principles
- Clean UI structure with scalable patterns

---

## 🛠 Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Lucide Icons

---

## 📦 Installation

```bash
git clone <your-repo-url>
cd <your-folder>
npm install
npm run dev
```

## 📌 Notes

- Logo images are sourced from external URLs (Pinterest) for demo purposes.
- Bookmark state is currently stored locally per card.
- This project focuses on UI architecture and component design rather than backend integration.
